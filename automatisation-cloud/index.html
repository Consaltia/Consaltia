Automatisation

Automatisation des tâches et services cloud

Les tâches répétitives faites à la main coûtent du temps et produisent des erreurs. Beaucoup se scriptent en quelques heures.

Ce qui se prête bien à l'automatisation

  • Renommage, tri et classement de fichiers en masse
  • Extraction de données depuis des fichiers Excel ou CSV
  • Consolidation de plusieurs fichiers en un rapport unique
  • Génération de documents à partir d'un modèle
  • Sauvegardes planifiées, en local et vers le cloud
  • Récupération périodique de données depuis un site ou une API
  • Envoi automatique de rapports par email

Comment savoir si ça vaut le coup

Le calcul est simple et je le fais avant de proposer quoi que ce soit : une tâche de vingt minutes répétée chaque semaine représente une quinzaine d'heures par an. Si le script prend une journée à écrire, il est rentabilisé en quelques mois et il ne se trompe pas.

À l'inverse, une tâche faite trois fois par an ne mérite pas d'être automatisée. Je vous le dirai.

Services cloud

  • Mise en place d'un stockage cloud avec des partages propres
  • Sauvegarde automatique des postes vers le cloud
  • Synchronisation de fichiers entre plusieurs machines
  • Choix d'un fournisseur adapté au volume et au budget
  • Bases d'AWS ou d'Azure pour un premier usage

Un script d'automatisation doit rester compréhensible par quelqu'un d'autre que son auteur. Je livre le code commenté et une note qui explique comment le lancer, le modifier et le désactiver.

Technologies

Python pour l'essentiel des traitements, PowerShell ou Bash selon le système, et les API des services concernés. Le choix suit le contexte, pas une préférence.
